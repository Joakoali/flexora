# flexora

Landing page of Flexora Design — estudio de desarrollo web, marketing digital y branding.

## Desarrollo

```bash
npm install
npm run dev        # http://localhost:3000 (redirige a /es o /en)
npm run test       # unit y componentes (Vitest)
npm run e2e        # end-to-end (Playwright)
npm run build
```

Copiá `.env.example` a `.env.local` y completá el número de WhatsApp y la URL pública.
